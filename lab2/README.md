# Лабораторная работа № 2 — Flexbox

Маслобоев Лев, УБ25-09Б. Вариант 3. Последние цифры студенческого билета: 48.

## Запуск

Откройте `index.html` в браузере или из папки репозитория запустите:

```sh
python3 -m http.server 8000 --directory lab2
```

## Задание 1 — digits.html / digits.css

Цифры 48 собраны из квадратов 32 × 32 px. Внутри body используются только div.
Flexbox выстраивает квадраты в строки и цифры и центрирует результат по двум осям.
Единственный заданный цвет — #222. Свойства position, left, top, bottom, right,
margin и padding не используются. Стандартный отступ body 8 px с каждой стороны
учтён в размерах контейнера через calc, чтобы его центр совпадал с центром экрана.

## Задание 2 — layout.html / layout.css

Адаптивная вёрстка варианта 3 из предоставленного task.html?id=3.
Для него генератор выбирает комбинацию [3, 1, 4, 0, 0].
Расположение задано Flexbox, без JavaScript, Canvas, Grid и абсолютного позиционирования.
Промежуточные контейнеры на отдельных ширинах используют display: contents,
чтобы их дочерние блоки участвовали в общем Flexbox-потоке.

Контрольные ширины: 320, 768 и 1200 px. Переходы: 768 и 1200 px.
Максимальная ширина макета — 1200 px. Ячейка по вертикали — 150 px согласно
Task.docx (в демонстрационном генераторе — 100 px). Цветная область имеет
отступ 15 px от краёв ячейки, как в образце. На мобильном экране используется
12 долей фактической ширины: исходный генератор для кнопки 320 px рисует Canvas
шириной 360 px, здесь макет адаптирован к реальным 320 px без горизонтальной прокрутки.

## Проверка

В Chromium проверены координаты, размеры и видимость каждого цветного блока
по данным генератора для варианта 3 на всех трёх контрольных ширинах.
Все блоки совпали с учётом высоты строки 150 px и адаптации к ширине экрана.
Горизонтальной прокрутки нет. Центрирование цифр проверено при 768 × 900
и 1200 × 900 px. Первая лабораторная работа не изменялась.
